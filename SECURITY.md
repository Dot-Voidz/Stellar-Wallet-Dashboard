# Security Policy

## Reporting

Do **not** file public issues for vulnerabilities that could expose secret keys or funds.

Prefer a private [GitHub Security Advisory](https://github.com/Dot-Voidz/Stellar-Wallet-Dashboard/security/advisories/new) or contact an organization owner with reproduction steps and impact.

## Safe usage

- Prefer **testnet** for demos and contributor work.
- Never commit, screenshot, or paste funded mainnet secret keys.
- Treat this dashboard as a developer convenience UI, not a production custody wallet.
- Clear browser state after demos on shared machines.
