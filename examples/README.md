# Examples

This folder contains small standalone demos that showcase core Stellar features used by the dashboard.

## Available examples

1. Wallet generation demo
   - Shows how to create a new Stellar keypair locally.
   - File: [wallet-generation.html](wallet-generation.html)

2. Balance lookup demo
   - Shows how to load an account and display balances from Horizon.
   - File: [balance-lookup.html](balance-lookup.html)

3. Payment builder demo
   - Shows how to build a simple payment transaction for the Stellar network.
   - File: [payment-builder.html](payment-builder.html)
