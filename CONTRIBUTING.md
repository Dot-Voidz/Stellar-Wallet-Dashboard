# Contributing to Stellar Wallet Dashboard

Thanks for your interest in contributing! This repository is intentionally small and simple, so contributions that improve usability, documentation, accessibility, or developer onboarding are especially welcome.

## How to contribute

1. Fork the repository.
2. Create a new branch for your change.
3. Open an issue first if your change is non-trivial.
4. Make your changes and test locally.
5. Open a pull request with a clear summary and testing details.

## Issue workflows

Use the issue templates when opening new issues:
- **Bug report** for errors and unexpected behavior.
- **Feature request** for enhancements and new features.
- **Question** for usage or design questions.

This helps maintainers triage issues faster and keeps the roadmap organized.

## Local development

This project is a static website. To run it locally, open `index.html` in a browser. For a simple local server, use any static-server tool or the following command if you have Python installed:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Recommended contributions

We are especially happy to receive:
- UI improvements and responsiveness fixes
- Better wallet security guidance and warnings
- New Stellar feature ideas like memo support, transaction history, or QR code sharing
- Documentation updates, especially for new contributors

## Pull request guidelines

- Keep changes focused and scoped.
- Use clear commit messages.
- Reference the issue number when applicable.
- Add any testing steps in the PR description.

## Code of Conduct

Be respectful and collaborative in all interactions.
